# Moonrise

Top-down pixel survival game built in Godot 4.7.

Gather planks and scrap by day, patch up the fence rings around your farmhouse, craft traps and upgrades, and try to hold out through the Blood Moon.

## Running
Open `RedMoon/project.godot` in Godot 4.7+ and hit F5.

## Controls
- **WASD / Arrows** — Move
- **Left Click / Space** — Melee swing
- **Right Click** — Shoot bow (hold to charge; right-click cancels trap placement)
- **E** — Grab planks / repair fences / open gates & house door / search ruins (hold)
- **Q** — Shockwave
- **1 / 2 / 3** — Place Spike, Bear Trap, or Fire Lure
- **U** — Upgrades & crafting
- **I** — Backpack
- **Esc** — Pause
