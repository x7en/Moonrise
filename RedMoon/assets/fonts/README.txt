Place your retro pixel font (.ttf) in this folder to style all in-game text!

Option 1 (zero code edits):
  Rename your font file to: pixel_font.ttf
  (Full path: RedMoon/assets/fonts/pixel_font.ttf)

Option 2 (keep original filename):
  Copy KiwiSoda.ttf or dogicapixel.ttf here, OR edit PIXEL_FONT_PATH in
  RedMoon/scripts/config.gd to match your filename.
